# Eureka Boom 学习平台：公开源码快照

这是“未来工程实验室”课程平台 MVP 的**代码与部署脚本快照**。包括 Node.js 服务、前端、JSON/MySQL 数据层和资料导入脚本。仓库不包含学生提交、课堂数据、上传文件、课件 PDF/Word、课程内容库或部署包。

## 本地运行

需要 Node.js 20+。先建立空白的本地数据文件，再启动：

```powershell
Copy-Item data/store.example.json data/store.json
npm install
npm start
```

打开 `http://127.0.0.1:3000`，健康检查地址是 `http://127.0.0.1:3000/api/health`。空白数据只用于检查应用能否启动，页面中的课程与资源需要自行录入。`data/store.json` 与 `data/uploads/` 被 Git 忽略。

## 仓库范围

| 目录 | 内容 |
| --- | --- |
| `public/` | 页面与浏览器端逻辑；未附带原本的图片和课件 |
| `db/` | MySQL 表结构与 JSON 数据导入代码 |
| `scripts/` | 本地资料导入和打包脚本；部分脚本需要本仓库未附带的原始课件，不能直接执行 |
| `.env.example` | 仅含占位值的配置示例，不是可用密钥 |

部署资料和真实数据没有随此快照发布。此版本仍是单教师演示/MVP；教师工作台缺少完整登录与权限保护，**不要直接开放到公网**。公开源码不代表服务已经上线，也不代表经过学生、家长或真实设备验证。

## 后续工作

在任何正式部署前，需要补齐教师认证、学生与家长权限、上传检查、内容审核、备份和隐私保护；再用匿名测试数据验证完整流程。不要把 `.env`、`data/store.json`、上传文件或真实课堂记录提交到仓库。
